Problem Diagnosis

当前设计六大问题

当前网站结构完整、文案专业，但视觉层面缺乏金融机构应有的厚重感与稀缺感。 以下六个核心问题导致整体观感「不高级」。

01
Hero 首屏过于平淡

浅色暖珠光底 + 极淡地籍线，视觉冲击力不足。顶级机构首屏通常使用暗色调全幅影像或视频背景，第一眼即建立权威感。

02
卡片设计缺乏材质感

白底 + 细边框的卡片是通用 SaaS 模板做法。高级金融网站使用毛玻璃、深色底 + 金色微光边框，营造稀缺材质感。

03
字体缺乏层次对比

全站使用 Inter 单一字族，标题与正文差异不大。引入衬线展示字体（如 Cormorant Garamond）可立即建立编辑式奢华感。

04
无数据可视化

68% GGR、四大资产板块等核心数据淹没在文字中。顶级机构用超大字号数字 + 金色渐变展示关键指标，强化记忆点。

05
布局过于对称单调

所有内容居中对齐，缺乏视觉节奏。编辑式不对称布局（7/5 分割、大序号、引述区块）能创造阅读层次与高级感。

06
色彩对比度不足

浅色背景 + 深蓝文字，整体偏「安全」。暗色主背景 + 金色点缀是金融奢华的经典语言，能显著提升品牌调性。

Design Philosophy

四大设计理念

参考全球顶级另类投资机构网站设计语言，提炼四条核心设计原则。

暗色为底 · 金色点缀

深蓝/近黑底色传递稳重、权威、稀缺感；金色（#C5A572）作为唯一强调色，用于分割线、数字、按钮，克制而精准。Blackstone、KKR 均采用此策略。

衬线标题 · 无衬线正文

标题使用 Cormorant Garamond 衬线体，自带编辑式奢华气质；正文保持 Inter 无衬线体，确保可读性。字族混搭是奢侈品牌经典手法。

大数字 · 强记忆

关键数据（68% GGR、4 大资产板块、15+ 年经验）以 3-5rem 超大衬线数字 + 金色渐变呈现，配合滚动触发计数动画，形成视觉锚点。

毛玻璃 · 层次感

卡片使用 backdrop-filter 毛玻璃效果 + 金色微光边框，在暗色背景上营造材质深度。Hover 时金线展开 + 卡片上浮，微交互精致而不喧宾夺主。

Implementation Roadmap

分三阶段实施路线

按影响优先级分三阶段推进，每阶段独立可交付、可部署。

1

Phase 1 · 高影响

视觉基底重构

  • globals.css 色彩令牌从浅色改为暗色系
  • 引入 Cormorant Garamond 衬线展示字体
  • Hero 首屏从浅色暖珠光改为暗色渐变
  • 地籍图母题线条从蓝改为金色低透明度
  • 导航栏适配暗色模式（白字 + 金色高亮）
  • 页脚从居中文字改为多列布局
2

Phase 2 · 中影响

组件质感升级

  • 卡片改为毛玻璃效果 + 金色微光边框
  • 卡片序号改为衬线体大号金色数字
  • Hover 效果增加金线展开 + 上浮动画
  • 新增核心数据展示区（大数字 + 金色渐变）
  • 品牌理念区改用更深渐变 + 金色引号装饰
  • CTA 按钮改为金色描边 + 填充动画
3

Phase 3 · 精细化

交互与细节打磨

  • 滚动触发数字计数动画
  • RevealSection 动效曲线优化
  • 移动端暗色适配 + 金框动画精简
  • 子页面 PageHero 统一暗色风格
  • 表单输入框暗色样式适配
  • 性能优化：字体子集化 + CSS 压缩
